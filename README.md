# tiny quantum lab

**Interactive quantum physics simulations for curious minds.**

tiny quantum lab is a free, browser-based collection of interactive experiments designed to help beginners explore quantum physics by experimenting first and learning the physics behind what they observe.

## Explore the experiments

- **Double-slit interference** — See how individual detections build an interference pattern.
- **Quantum tunneling** — Explore how a quantum particle can have a nonzero probability of appearing beyond a barrier.
- **Wave packets** — See how quantum states can be localized, move, and spread.
- **Photoelectric effect** — Discover why the energy of individual photons matters more than brightness alone.
- **Atomic energy levels** — Explore why atoms emit photons with specific energies and colors.
- **Entanglement** — Compare measurements from entangled particles and explore their correlations.
- **Quantum computing** — Experiment with qubits, quantum gates, superposition, and measurement.

## How it works

Each experiment starts with a question.

**Ask → Predict → Play → Notice → Understand**

Change the controls, make a prediction, run the experiment, and then use the explanations to connect what you observe to the underlying physics.

You do not need a quantum physics background to get started.

## Run it locally

The project uses plain HTML, CSS, and JavaScript, so there is no build system or package installation required.

1. Clone the repository:
   ```bash
   git clone https://github.com/fikirgetnet123-rgb/tiny-quantum-lab.git
   ```
2. Open `index.html` in a browser.

You can also use the live version directly:

**[Open tiny quantum lab](https://fikirgetnet123-rgb.github.io/tiny-quantum-lab/)**
